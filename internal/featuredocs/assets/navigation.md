# Ceraa feature navigation

Use these bundled guides for feature use, not source architecture:

- `browser.md`: browser actions, session flow, and safe navigation.
- `goals.md`: persistent goals and plans.
- `skills.md`: approved skills and feedback proposals.
- `miniapp.md`: Telegram Mini App user features.
- `authentication.md`: provider sign-in and account selection.
- `setting-secrets.md`: encrypted user secrets and safe command use.

Read the guide that matches the task before guessing. These files describe the
installed Ceraa feature surface. They do not replace repository instructions or
source inspection when changing code.
