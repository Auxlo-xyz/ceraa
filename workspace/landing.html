Interactive CLI & Telegram

Interact directly via the command-line interface or spin up the Telegram bot for remote agentic workflow management.

Robust Tool Dispatcher

Full suite of file editing, code search, bash execution, persistent goals, and web fetching capabilities built right in.

Secure & Modular

Clean Go codebase adhering to strict security standards, secret management, session persistence, and rigorous validations.

Clean Architecture

Organized into modular internal packages for extensibility.

cmd/

CLI commands root, setup, and telegram handlers.

internal/agent/

Core reasoning loop, state, and tool integration.

internal/config/

Environment and configuration management.

sessions/

Persistent active state, locks, and history logs.

Quickstart

Get up and running with Ceraa in seconds.

Terminal

# Clone the repository
git clone https://github.com/emperormk01/ceraa.git && cd ceraa

# Build the binary
go build -o bin/ceraa main.go

# Run setup or start CLI
./bin/ceraa setup
